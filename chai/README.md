## Overview

Chai is a signed three-valued algebra on D = {-1, 0, +1}. It is obtained from Boolean negation `not(b) = 1 - b` by turning its constant into a variable: `DIF(a, b) = sgn(a - b)`. The paper defines seven operations (SYN, DIF, OR, XOR, AND, NOT, ANT), proves which clones they generate (zero-fixing, odd, Boolean-preserving), and classifies all 127 nonempty subsets of the seven operations: 40 are functionally complete without nullary constants, 95 with the constants 0, +1, -1.

The paper contains its own proofs for every arity. The code here checks the finite parts by computer: truth tables, explicit terms, exhaustive closures and the classification of the 127 subsets.

## Quick check for reviewers

Requirements: Python 3.10 or newer; numpy only for `chai_checker.py`.

```
cd verification
sh run_all.sh
```

This takes about 25 seconds. Every script stops at the first failed assertion, and `run_all.sh` stops at the first failing script. A successful run prints, among others, `ALL ASSERTIONS PASSED` (checker scripts) and `ALL 123 CHECKS PASSED` (`chai_verify_v1_increments.py`), and ends by writing `chai2026v1_supplement.tex` and `SHA256SUMS`.

To compile the paper: `pdflatex Chai2026v1_EN.tex` (three runs; `IEEEtran.cls` is part of standard TeX distributions). The supplement needs `pdflatex` twice.

The five exhaustive closures (19 683 and 6561 binary functions) take about 5 minutes: `sh run_all.sh --full`. Their results are shipped in `results.json` and `results_consts_*.json`, so the default run does not recompute them.

## Where each claim of the paper is checked

| claim in the paper | script | shipped result |
|---|---|---|
| derivation of DIF, minimal carrier, the three sections; printed Tables I-III | `chai_verify_v1_increments.py` | `chaiv1_increments_results.json` |
| polarization AND = DIF(OR, XOR), involution (SYN, DIF) | `chai_checker.py`, `check_c9_chain.py` | `results.json` |
| Theorems 3-5: explicit terms generate Z_n, the odd operations, the Boolean-preserving operations | `chai_verify_v1_increments.py` (every binary function of each class) | `chaiv1_increments_results.json` |
| Theorem 6: 40 of 127 complete, 95 of 127 with constants | `classification_table.py`, `independent_free_constants.py` | `classification_127.csv` |
| Table IV: closures with the constants (all 19 683 functions) | `chai_checker.py --full-consts` | `results_consts_*.json` |
| difference lift, 2862 orbits, T9ID words, XY3/G3 tables | `check_c9_chain.py`, `verify_direction_rotation.py` | `direction_rotation_results.json` |
| the 27 unary functions as terms (Supplement S5) | `chai_checker.py`, `independent_check.py` | `unary_catalogue.csv` |

The supplement ([PDF](https://github.com/bitritware/logic/blob/master/chai/paper/chai2026v1_supplement.pdf), sections S0-S19) lists the same map in S11 and states in S12 what the computations do and do not establish. Finite checks support the paper but do not replace its arbitrary-arity proofs.

## Reproducibility notes

- `results*.json` record the Python and numpy versions used; on another machine compare the results, not the whole files.
- The closures with constants are shipped from earlier verified runs for the same seven operations; `chai_verify_v1_increments.py` checks the paper's Table IV against them.
- `SHA256SUMS` is rewritten by `run_all.sh`; check a fresh copy with `sha256sum -c SHA256SUMS` before running.
